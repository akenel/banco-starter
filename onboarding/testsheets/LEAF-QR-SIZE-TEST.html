🌿 Leaf QR — which size actually scans?

Click the box, scan each five times with both guns. Each code names itself, so the log tells you exactly which survived. A is the control — if A fails, the size is wrong, not the leaf.

Why F fails: a square leaf at 30% covers 9% of the code's area. The 30% figure came from testing the Artemis logo, which is 1.65x wider than tall — in the same box it only covered 5.4%. Same percentage, nearly double the damage.

Why B should win: a bigger QR with a smaller percentage puts the leaf at 4.8mm — larger than the 4.5mm that's live now — while cutting damage back to 5.8%.
