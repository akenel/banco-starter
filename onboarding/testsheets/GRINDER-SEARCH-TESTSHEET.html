A · The article number — the fastest way in, and it needs no sticker

🔢 A1 · Type the full number shipped 2026-08-06

Every grinder already carries one. 191 of 192 have a TAM- SKU and all 192 are distinct. Measured: the full 5 digits returned exactly one product 300 times out of 300. This is the route that needs nothing stuck to the goods.

Search on /pos/catalog — type just the digits, no TAM-.

  1. Type 24350 Grinder "Flower Mill" Next-Gen Premium 3tlg. 66mm schwarz — CHF 99.00, first
  2. Type 4619 Grinder Metall 3teilig mit Sieb Poker Chip 42mm — CHF 9.90
  3. Type 23357 Grinder Alu 3-teilig Santa Cruz Shredder L Grün — CHF 95.00
  4. Type TAM-24350 — the whole SKU, as it appears on a shelf label same product as step 1
  5. ⏱️ Time one lookup — number typed to product on screen. under 5 seconds. Write the actual number in the note.

🔴 A2 · The bug this fixed — a 4-digit number that is also the start of a 5-digit one

Angel found it: "if you type 1002 well then good luck." A bare 4-digit type hit 15 products at worst. Before the fix, searching 1166 put the exact TAM-1166 last of four, under TAM-11666.

  1. Type 1166 Messingsieb rund 20mm 5 Stk. (TAM-1166) is FIRST — not TAM-11666
  2. Type 1131 Metall-Kopf konisch Hanfblatt (TAM-1131) first, above TAM-11315
  3. Type 2584 Smoking King Size black De Luxe (TAM-2584) first, above TAM-25847
  4. The near-misses should still be visible underneath, not hidden — you may have typed 4 digits of a 5-digit code. exact one on top, the others still listed
B · The size — 165 of 192 grinder names carry a diameter

📏 B1 · Search by millimetres shipped 2026-08-06

Diameter is the first thing a customer asks and the best-covered spec on the shelf. It was not understood until today: searching 62 mm returned a DynaVap condenser, a skateboard and two 6mm filters in the top four.

  1. Type 62mm 62mm grinders at the top
  2. Type 62 mm — with a space, the way a person types the SAME results. This is the case that was broken.
  3. Type grinder 62mm — two words 62mm grinders, not 6mm filters
  4. Type 50mm, then 42mm each floats its own diameter
  5. ⚠️ Check nothing vanished. 27 grinders state no diameter. Search grinder and confirm you still see grinders with no mm in the name. they are still there — the size is a SORT, never a filter
C · Name and category — the fallback, and the naming problem

🔤 C1 · Two words off the object

Angel: "the descriptions are not consistent." Measured — 49 grinders state no material, 66 state no part count. This part is as much about finding the gaps as testing the search.

  1. Type santa cruz the Santa Cruz Shredders
  2. Type flower mill the Flower Mill range
  3. Type grinder 4teilig, then grinder 4 teilig with a space both work — note it if they differ
  4. Pick up three real grinders and try to find each by typing two words you can read off the object. 3/3. Write down any you could NOT find and what you typed.
D · The photo route — measure ONE number

📷 D1 · Ten grinders through snap-find this decides the batch tool

The whole point of this part is a hit rate. Batch upload only saves the upload clicks — it cannot batch the decisions. So: 7+/10 → building a batch tool is worth it. Poor → batch would just be a faster way to fail, and the answer is typing names off the photos.

⚠️ The button is not where you expect. /pos/catalog → + New product → the indigo box at the top → ✨ snap-fill. The file picker in the scan overlay is the BARCODE reader — on a grinder it correctly says No MultiFormat Readers were able to detect the code, which reads like the AI failed. It was never called. (Filed: the AI tool is gated behind "create", which is backwards.)
  1. Photograph 10 grinders — one shot per model, price sticker in frame if there is one. 10 photos on the phone
  2. Run each through ✨ snap-fill. For each, tick one: ① found the right grinder · ② found something, wrong one · ③ found nothing. write the tally in the note — this is the number that matters
  3. Does it search the 420 reference, not just our catalogue? reference matches appear as well as catalogue matches
  4. ⏱️ Time one photo → confirmed product. compare with 47 s/row measured on the papers shelf
  5. 🔬 Also try Google Lens on the same 10, on the phone. Different engine, whole-web reverse image search. two tallies, same 10 grinders — which wins?
E · The label — Felix's decision, not ours

🏷️ E1 · Does an 18 mm label even fit?

The 2026-07-29 scan tests showed 18 mm reads as cleanly as 20 mm, so a genuinely small sticker exists. Test it physically before offering it.

  1. Print one 18 mm label and stick it on the smallest grinder in the shop. it fits, and looks acceptable on a CHF 20 object
  2. Scan it with the gun, off the curved surface. reads first time — a grinder is round, which a flat test does not prove
  3. Try it on the largest one too. one size works across the range, or you need two

🗣️ E2 · The conversation with Felix — bring a choice, not a request

Rafi already stickers every grinder with a price. So Felix is not objecting to marking the product — that happens today. Find out which objection it really is, because two of the three are not true:
  • "It'll look ugly" → a design problem. Ours can be neater than what is on there.
  • "More work for Rafi" → it is the same work — one label, either way.
  • "Customers pick them up" → the only one needing an alternative.
  1. Ask it as: "You already put a price sticker on every grinder. What if that same sticker had the number on it too?" — number in plain text, not a barcode. his actual answer, in his words
  2. If no: offer the scan card — thumbnail · name · price · barcode, 4–6 A4 pages at the till. Nothing marked, and it shows a picture to match against. yes / no / "let me think"
  3. Ask what he wants for bongs — 952 rows with no barcode, and the month's biggest sales were hardware (398.– · 307.– · 300.–). a direction, not a decision — bongs are not today's job
