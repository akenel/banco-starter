What this is. Four CBD products in the UAT catalog are classed standard and can be rung up with no 18+ check. The classifier now catches them, but a classifier fix doesn't touch rows already in the table — this sheet walks the data fix and proves it worked at the till, not just in a report.
Why this matters more than a normal bug. Whether a customer was asked for ID depended on how someone typed a product title — the live CDB was a transposition made while copying off a package at the counter. A CBD product sold un-gated is a compliance failure, not a UX annoyance.
The one rule: it only ever TIGHTENS. A row changes only when the classifier says age-restricted and the stored row says it isn't. It never un-gates a product and never relaxes a class a manager set deliberately.

Worst case of a bad run is a product that asks for ID when it needn't — annoying, fixable in the cleanup cockpit. The opposite is what we're fixing.
Dry run already caught one bad change. The first version proposed 16 updates and 12 were wrong — storage tins, filters and empty cones. Nothing was written, because dry run is the default. That is the point of Part A: read the list before you apply it.
Part A — see what it wants to change (writes nothing)

A1 · Run the dry run

Read-only. Safe to run any time, on any environment.

  1. On the UAT box: cd /root/banco-starter && git pull python3 scripts/reclass-age-gate.py it scans ~5,166 active products and prints a list. Nothing is written.
  2. Check the count is 4, and that the list is exactly these:
    Productbecomes
    CBD Gummycbd_hemp · 18+
    BLOW CDB PRE JOINT REDcbd_hemp · 18+
    BLOW CDB PRE JOINT GREEN Purecbd_hemp · 18+
    BLOW Joint GREY Purecbd_hemp · 18+
    all four are genuinely CBD products that should ask for ID.
  3. Read every line before going further. If anything appears that is a container, filter, paper or cone — a Joint-Pack, a Smellproof Tube, a CTIP filter, a G-Rollz cone — stop and mark this FAIL. the list contains only things a customer consumes, never things that hold or make them.
Part B — apply it

B1 · Write the changes

  1. Same command with --apply. It shows the list again and asks first: python3 scripts/reclass-age-gate.py --apply prompts Apply these 4 change(s)? [y/N] — answer y. Then "✅ tightened 4 product(s)."
  2. Run the plain dry run again. python3 scripts/reclass-age-gate.py "✅ nothing to tighten" — proves it's idempotent and the writes landed.
Part C — prove it at the till (the part that counts)

C1 · The gate actually fires

A report saying is_age_restricted = true is not proof. A cashier being stopped is proof.

  1. New Sale → add BLOW Joint GREY Pure to the cart. the 18+ / ID prompt appears before checkout completes.
  2. Same for BLOW CDB PRE JOINT RED — the one whose title has the CDB typo. gated. This is the exact product that leaked, and the typo no longer matters.
  3. Check the product page shows the 🔞 badge and class cbd_hemp. badge visible in the catalog list and on the detail card.

C2 · It does NOT fire where it shouldn't just as important

Over-gating is its own failure. Staff learn to wave away a prompt that fires wrongly — and then the real ones get waved through too.

  1. Sell a Joint-Pack (any) — a storage case. no ID prompt. It holds joints; it isn't one.
  2. Sell G-Rollz Prerolled (any flavour) — empty cones. no ID prompt. Pre-rolled here means the paper is pre-formed.
  3. Sell Cone+ CTIP Filter and any Smoking / RAW papers. no ID prompt on either.
  4. Sell a CBD oil or CBD seeds if the catalog has one. no ID prompt — oils and seeds are cbd_open, deliberately not gated.
Part D — after any capture session

D1 · Make it a habit

  1. Whenever a batch of products has been added by hand, re-run the dry run. python3 scripts/reclass-age-gate.py catches anything typed in under time pressure that the classifier now understands. Idempotent, read-only, ten seconds.
  2. If it proposes something that looks like an accessory, don't apply it — that's a classifier bug, and it's worth a BL. the list stays boring. A surprising entry is information.
Known limit. A title too thin to classify — the live example is Blow pure — can't be caught automatically without over-gating half the shelf. Products like that need a human to set the class in the cleanup cockpit. The script is a safety net, not a substitute for knowing your own stock.
